# Data schema and provenance

This schema describes the checked-in source and derived tables as inspected on 2026-09-30. UTC is the storage timezone. The frontend may format timestamps in `Asia/Kolkata`, but must retain the UTC timestamp as provenance.

## Normalized records

### Station

| Field | Source | Type | Notes |
|---|---|---|---|
| `station_id` | OpenAQ location | string | Stable location ID; preserve as a string. |
| `station_name` | OpenAQ location | string | Source label. |
| `latitude`, `longitude` | OpenAQ location | number | WGS84 degrees; all 220 current rows fall within legal coordinate bounds. |
| `district` | OpenAQ location / explicit locality alias | string or null | Blank for all stations in the inspected snapshot. Never infer from the name. |
| `provider`, `owner` | OpenAQ location | string or null | Source/provider metadata, not independent validation. |
| `timezone` | OpenAQ location | IANA timezone | All 220 rows currently report `Asia/Kolkata`. |
| `is_monitor`, `is_mobile` | OpenAQ location | boolean | Provider-reported flags; do not treat as a quality score. |
| `reference_priority` | Pipeline derivation | number/string | Ranking hint only; not a certification. |

### AirQualityObservation

Grain in the processed pipeline: `(station_id, UTC hour)`. `air_quality_hourly.csv` has 72 rows in the current snapshot, all for `station_id=2860223`; the intended 220-station schema is not evidence that 220 stations have measurements.

| Field | Type | Unit / null behavior |
|---|---|---|
| `station_id`, `station_name`, `district`, `source_provider` | string / nullable string | Source location/provider fields. |
| `latitude`, `longitude` | number | WGS84 degrees. |
| `timestamp` | ISO-8601 string | UTC start of hourly measurement interval; unique in current sample. |
| `PM2.5`, `PM10` | number or null | µg/m³. Current sample has 51 PM2.5 readings, no PM10 readings. |
| `NO2`, `NOx`, `O3`, `CO`, `SO2` | number or null | ppb when supported by source units. NO2 is not mapped to NOx. All are missing in current sample. |
| `temperature` | number or null | °C. Current sample has 51 values. |
| `relative_humidity` | number or null | %. Current sample has 51 values. |
| `wind_speed` | number or null | m/s. |
| `wind_direction` | number or null | Degrees; meteorological direction the wind comes from. |

Missingness remains null/NaN. Unknown or unsupported units are not converted into a guessed value. Duplicate sensor-hour readings are deduplicated/averaged by the existing OpenAQ processor; its quality report tracks duplicate/invalid counts.

### MeteorologyRecord

Two products share meteorological variables but must remain distinct.

| Field | Type | Unit / meaning |
|---|---|---|
| `timestamp` | ISO-8601 string | UTC valid time. It is not an initialization/run timestamp. |
| `place` | string | One of the 10 configured NCR/outer-ring reference locations. |
| `grid_lat`, `grid_lon` | number | Resolved model grid point in WGS84. |
| `elevation` | number | Grid-cell elevation, metres. |
| `temperature_2m`, `dew_point_2m` | number or null | °C. `dew_point_2m` appears in the historical forecast export. |
| `relative_humidity_2m` | number or null | %. |
| `surface_pressure` | number or null | hPa. |
| `wind_speed_10m` | number or null | km/h, matching source API unit. |
| `wind_speed_10m_ms` | number or null | m/s, derived as km/h ÷ 3.6. |
| `wind_direction_10m` | number or null | Degrees, direction from which wind blows. |
| `cloud_cover` | number or null | %. |
| `precipitation` | number or null | mm per source hourly interval. |
| `boundary_layer_height_m` | number or null | m, only in historical forecast archive; null is not zero. |
| `shortwave_radiation` | number or null | W/m², only in historical forecast archive. |

`meteorology_hourly.csv` is the Open-Meteo archive of ERA5 reanalysis (hindsight). `forecast_hourly.csv` is the Open-Meteo Historical Forecast API archive. Neither is a current operational forecast. Both currently have continuous hourly valid-time records per location in the exported range; maintain the product distinction when querying or joining them.

### ForecastPoint (prototype replay)

The replay API has station-forecast rows keyed by a synthetic replay station ID and integer `hour` 0–71. Values include PM2.5, PM10, O3, NO2, PM2.5 p10/p50/p90, AQI proxy, PBLH, ventilation, temperature, wind, smoke index and driver summaries. These fields are generated by `SurrogateModelProvider`; they are deterministic **REPLAY / DEMO**, not observations, an operational forecast, a calibrated interval, or validated model output.

### FireEvent and validation result

No real FireEvent dataset or validation pairs exist. Replay fire seeds and particle frames are synthetic and only meaningful inside replay mode. The verification endpoint returns unavailable/blank metrics until matched forecasts and independent observations are supplied.

## Derived values and rules

- `wind_speed_10m_ms = wind_speed_10m / 3.6`.
- `u_wind = -speed × sin(direction)`, `v_wind = -speed × cos(direction)` for the wind-from convention; these are derived features, not independent measurements.
- Replay inversion uses `ISI = T925 − T2m`; real source data currently lacks T925/T850.
- Replay ventilation uses `VC = PBLH × wind speed`, with units m²/s.
- Replay AQI is the existing CPCB-style PM2.5 sub-index interpolation. It is not a regulatory multi-pollutant AQI.
- Replay PM2.5 p10/p50/p90 values are prototype interval values, not calibrated confidence bounds.
- Replay alert checks use `VC < 650 m²/s` for a stagnation watch and `ISI > 2 °C` for an inversion signal (`backend/app/config.py`). These are prototype diagnostics, not health advisories or validated thresholds; the real-data archive has no alerts.
- Feature lags/targets are station-local; no missing measurements are backfilled, interpolated, or replaced by zero.

## Source files without normalized UI records

OSM boundary, road and land-use JSON are source geometries in WGS84. Before browser use, select relevant NCR features, preserve OSM attribution, and simplify only as a documented cartographic transformation. Current UI geometry is schematic; station coordinates are real when sourced from OpenAQ metadata.

Raw CAMS, ERA5 pressure-level and FIRMS/fire files are absent from `data/`; metadata availability cannot substitute for those measurements.
